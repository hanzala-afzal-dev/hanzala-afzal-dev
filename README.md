## Featured project: Dynamic Throttle for Laravel

[Dynamic Throttle for Laravel](https://github.com/hanzala-afzal-dev/laravel-dynamic-throttle)
is an open source package that lets you change your rate limits while your app runs.

With the built in `throttle` middleware, every new limit needs a code change and a
deploy. Dynamic Throttle keeps the rules in your database instead. You can change a
limit from a dashboard, from Artisan or from code, and every server uses the new
limit within seconds.

- Limits per IP, user, API token, header or tenant
- Dry run mode: a new rule counts requests and shows who it would block, but it
  blocks nobody until you turn it on
- Exemptions with an end date, and emergency switches for incidents
- A dashboard with a live feed of blocked requests, an Explain page and an audit log
- Works on PHP 8.3+ with Laravel 12 and 13, using Redis, Valkey or another Laravel cache store

It is in public beta now, and you can install it from
[Packagist](https://packagist.org/packages/hanzala-afzal/laravel-dynamic-throttle).
Feedback is very welcome.
